# ご当地グルメ検索 v7.2

公開URL：https://fxsky2621129-tech.github.io/gotochi-gourmet/

「店舗を検索」またはEnterで、入力したキーワード・都道府県・カテゴリを使ってGoogleマップの店舗検索を同じタブで開きます。戻る操作で検索画面に戻れます。店舗一覧はGoogleマップ側に表示されます。

例：「人気グルメ・千葉」と入力して検索。または都道府県で千葉を選び「人気グルメ」を押します。クイック検索は入力済みの地名も保持します。都道府県とカテゴリの変更は条件を更新し、自動では画面移動しません。

食べログ・Retty・ホットペッパー・Tripadvisorへのリンクは削除しました。

現在地を使うと取得座標でGoogleマップの周辺検索を開きます。現在地検索を解除、または都道府県の変更で解除できます。位置情報は保存しません。最後の検索語は保存可能な場合のみ端末に保存します。

旧版の料理一覧・お気に入り・オフライン機能は提供しません。sw.jsは旧版Service Workerの終了処理です。GitHub Pagesはmainブランチのルートから公開します。

検索遷移、千葉のクイック検索、入力地域の保持、Enter・IME変換中の動作、条件変更、予約リンク削除、現在地解除をJavaScriptの模擬環境で確認しています。

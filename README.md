# ご当地グルメ検索 v7.1

キーワード・都道府県・カテゴリから、Googleマップ、Web、口コミサイトの検索リンクを作る静的ページです。

公開URL：https://fxsky2621129-tech.github.io/gotochi-gourmet/

## 使い方

検索語と都道府県を指定し「検索」を押します。Enterキーやカテゴリの選択でも入力中の検索語を反映します。検索結果はリンク先の各サービスで表示されます。

「現在地を使う」は位置情報の許可後、取得座標でGoogleマップの周辺検索を開きます。「現在地検索を解除」または都道府県の変更で解除できます。口コミサイトとWeb検索には現在地の座標は反映されません。

最後の検索語は保存可能な場合のみブラウザーに保存します。位置情報は保存しません。外部検索にはインターネット接続が必要です。

旧版の料理52品の一覧・お気に入り・アプリのインストール案内・オフライン機能は提供しません。旧版の端末内お気に入りは読み書きしません。

# ご当地グルメ検索

全国のご当地料理を検索できる、Androidのホーム画面に追加可能なブラウザーアプリです。

## 使い方

GitHub PagesのURLをAndroidのChromeで開きます。右上の「︙」→「ホーム画面に追加」→「インストール」または「追加」を選びます。そのままブラウザーでも利用できます。

料理データは47都道府県・52品です。全国一覧では都道府県名を開いて料理を表示でき、都道府県を選ぶとその地域の料理をすべて表示します。「人気グルメ」「食べ歩き」「道の駅グルメ」「名物スイーツ」は、選択した都道府県と入力した料理名・地名でGoogleマップを開きます。お気に入りと最後の検索語は端末のブラウザーに保存され、サーバーには送信しません。初回読み込み後は料理検索をオフラインで使用できます。Googleマップ・Web検索には通信が必要です。

「現在地を確認」は位置取得だけの機能です。現在地による絞り込みや近い順の並べ替えには対応していません。ブラウザーのサイトデータを消すと、お気に入りも消えます。

## GitHub Pages

Settings → Pages → Deploy from a branch → main / (root) → Save。

公開するのはこのフォルダーの静的ファイルだけです。署名鍵・APK・開発ツールは含みません。GitHub Pagesのページは公開URLから閲覧できます。

更新時は `sw.js` のキャッシュバージョンを変更してください。
